# Corner Grocer Item Tracking Program

## Project Overview

For this course, I selected the Corner Grocer Item Tracking Program, which showcases my skills in C++ and demonstrates my ability to write well-documented and readable code. This program addresses the need for effective inventory management by tracking item frequencies in a grocery store setting. It provides functionalities to search for item frequencies, print all items, and visualize item frequencies through histograms.

## Key Features

- **Functional Design:** The program allows users to interactively manage and track item frequencies, ensuring efficient inventory oversight.
- **Multiple Programming Languages:** The main focus is C++, which supports data structures and file handling.
- **Backup Functionality:** The program creates a backup file (`frequency.dat`) to preserve item frequency data, ensuring data integrity.
